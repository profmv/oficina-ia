Summary: Oficina IA is a public Portuguese learning path with browser-local progress.

Open https://profmv.github.io/oficina-ia/ . The path contains 24 weeks at six hours per week, 48 lessons, 36 formative questions, practical rubrics and three career routes.

Progress stays in the current browser and device. Export JSON regularly; clearing site data removes local progress. No personal notes, private governance, journals, databases or machine paths are published by this build. XP does not certify independent competence or guarantee income.
